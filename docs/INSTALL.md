# Tolki

Голосовые звонки и демонстрация экрана до 15 человек. Без серверов и аккаунтов: один из участников — организатор — открывает комнату на своём компьютере, остальные входят по ссылке-приглашению.

## Скачать

Все файлы — на странице [последнего релиза](https://github.com/nepriyatelev/tolki-releases/releases/latest).

| Система | Файл |
|---|---|
| Windows 10/11 (x64) | `Tolki-<версия>-win-x64.exe` |
| macOS, Apple Silicon (M1 и новее) | `Tolki-<версия>-mac-arm64.dmg` |
| macOS, Intel | `Tolki-<версия>-mac-x64.dmg` |
| Linux (x64), любой дистрибутив | `Tolki-<версия>-linux-x86_64.AppImage` |
| Debian, Ubuntu, Mint (x64) | `Tolki-<версия>-linux-amd64.deb` |

Какой Mac: меню Apple (яблоко в левом верхнем углу) → «Об этом Mac». «Чип Apple M…» — Apple Silicon, «Процессор Intel…» — Intel.

## Установка и первый запуск

Приложение не подписано платным сертификатом, поэтому при первом запуске система предупредит. Это нужно пройти один раз.

### Windows

1. Запустить `Tolki-…-win-x64.exe`.
2. Если появилось «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3. Установка пройдёт сама, на рабочем столе появится ярлык Tolki.

### macOS

1. Открыть `.dmg` и перетащить Tolki в «Программы».
2. Запустить Tolki из «Программ». macOS скажет, что не может проверить приложение, — нажать «Готово».
3. «Системные настройки» → «Конфиденциальность и безопасность» → внизу, у строки про Tolki, — «Всё равно открыть» и подтвердить паролем.

Если кнопки «Всё равно открыть» нет, то же самое делает команда в «Терминале»:

```sh
xattr -dr com.apple.quarantine /Applications/Tolki.app
```

### Linux

**AppImage** — установка не нужна:

```sh
chmod +x Tolki-*.AppImage
./Tolki-*.AppImage
```

При первом запуске приложение само добавляет себя в меню приложений и в обработчики ссылок `tolki://` — после этого приглашения открываются кликом. Если файл перенести в другую папку, достаточно один раз запустить его оттуда.

**.deb** (Debian, Ubuntu, Mint):

```sh
sudo apt install ./Tolki-*-linux-amd64.deb
```

## Разрешения

- **Микрофон.** Система спрашивает при первом входе в комнату — нужно разрешить. Без микрофона тоже можно войти: только слушать.
  - Если доступ запрещён, на macOS: «Системные настройки» → «Конфиденциальность и безопасность» → «Микрофон» → включить Tolki.
  - На Windows: «Параметры» → «Конфиденциальность и защита» → «Микрофон» → включить «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону».
- **Запись экрана (macOS)** — только для показа своего экрана. Когда разрешения нет, Tolki показывает кнопку «Открыть настройки»: там включить Tolki в разделе «Запись экрана» и перезапустить приложение.
- **Linux с Wayland:** какой экран или окно показать, спрашивает сама система.
- **Звук компьютера при показе экрана** — галочка «Звук компьютера» в окне «Что показать» (Windows; macOS 14.2 и новее). Участники слышат то, что играет на компьютере, — видео, игру, музыку; голоса из самого звонка в этот звук не попадают. На macOS при первом показе со звуком система попросит разрешение на запись системного звука — его нужно дать. На Linux галочки нет: там Electron захватывает только весь звук колонок, вместе с голосами звонка, и участники слышали бы себя с задержкой. Видео и игры можно показать без звука.
- **Говорить по клавише (push-to-talk)** — по желанию, в «Настройках звука» в звонке: «Говорить, только пока нажата клавиша». Голос уходит, только пока клавиша зажата.
  - **macOS:** чтобы клавиша работала поверх других окон и игр, система попросит разрешение «Универсальный доступ» («Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» → включить Tolki). Без него клавиша работает, когда окно Tolki активно.
  - **Linux с Wayland:** клавиша работает, только когда окно Tolki активно — Wayland не даёт приложениям видеть клавиши в других окнах.
- **Клавиши в любом окне** — по желанию, там же в «Настройках звука»: сочетания для микрофона и звука (с Ctrl, Alt или Cmd), которые работают в звонке, даже когда окно Tolki не активно. По умолчанию не заданы. Пока идёт звонок, заданное сочетание не достаётся другим приложениям; если его уже заняло другое приложение, Tolki так и напишет. На Linux с Wayland система может спросить, разрешить ли Tolki это сочетание.

## Войти в комнату

1. Открыть ссылку-приглашение `tolki://…` — приложение подхватит её само. Или вставить ссылку на главном экране в поле «Ссылка-приглашение» и нажать «Войти».
2. Ввести имя — его увидят участники. Если в комнате есть пароль, он у организатора (бывает, что пароль уже вшит в ссылку).
3. «Войти в комнату».

Ссылка работает, только пока организатор держит комнату открытой.

## Открыть комнату (стать организатором)

Внизу главного экрана Tolki пишет, может ли этот компьютер быть организатором. Если написано «Этот компьютер может быть организатором» — «Создать комнату», «Открыть комнату», и организатор сразу в звонке. Ссылку для участников копирует «Скопировать ссылку» на экране комнаты или «Пригласить» в звонке. «Выйти» у организатора закрывает комнату для всех.

- Комната принимает подключения на порту **47000** (TCP и UDP). Обычно Tolki открывает его на роутере сам; другой порт можно указать при создании комнаты в «Дополнительно».
- **Windows** при первом открытии комнаты может спросить, разрешить ли Tolki доступ к сетям, — нужно разрешить, иначе участники не подключатся.
- Пока комната открыта, компьютер организатора пересылает всем голос и экран, поэтому важна его исходящая скорость. В «Проверке сети» на экране создания комнаты Tolki замеряет её и пишет, на сколько человек хватит, например: «Отдача 25 Мбит/с — хватит на 14 человек и экран в 1080p».

**Права организатора:**
- **Подтверждать вход** — галочка при создании комнаты или замок в шапке звонка. Вошедший по ссылке ждёт, пока организатор нажмёт «Впустить» («Отклонить» — не пустить). Выключение впускает всех, кто ждёт. Если у участника оборвалась связь, при переподключении он возвращается без нового подтверждения.
- **Удалить из комнаты** — «⋯» на плитке участника. Участник отключается; войти снова он может по той же ссылке (при включённом подтверждении — только после «Впустить»).

### Если «Этот компьютер не может быть организатором»

Причину Tolki пишет там же, а в «Что можно сделать» — что поможет. Самые частые случаи:

| Что написано | Что делать |
|---|---|
| Включён VPN | Выключить VPN на время созвона или добавить Tolki в исключения VPN (split tunneling, «раздельное туннелирование»). |
| Роутер не открывает порты автоматически | Включить UPnP в настройках роутера или пробросить порт 47000 (TCP и UDP) вручную: настройки роутера (обычно http://192.168.1.1 или http://192.168.0.1) → «Проброс портов» / «Port forwarding». |
| Двойной NAT: роутер подключён через модем провайдера | Режим моста (bridge) на модеме провайдера или проброс порта на обоих устройствах. |
| Провайдер выдаёт общий адрес (CGNAT) | Проброс порта не поможет. Поможет белый IP у провайдера — обычно за небольшую плату. |

Если написано «Этот компьютер может быть организатором через IPv6», подключиться смогут только участники, у которых тоже есть IPv6. Если провайдер даёт IPv6, его можно включить в настройках роутера.

Если ничего из этого не подходит — организатором может быть другой участник: комнату может открыть любой, у кого внизу главного экрана написано «Этот компьютер может быть организатором».

Если Tailscale установлен у всех участников, в ссылке можно заменить адрес после `h=` на адрес Tailscale компьютера организатора (`100.x.y.z`) — тогда порт пробрасывать не нужно.

## Закрытие окна и трей

Крестик окна не завершает Tolki: звонок и открытая комната продолжаются.
- **Windows и Linux:** Tolki уходит в трей (значок рядом с часами). Щелчок по значку открывает окно; в меню значка — микрофон, звук и выход из звонка, «Сворачивать в трей при закрытии» (если снять, крестик завершает Tolki) и «Выйти из Tolki». На Linux значок в трее показывают не все окружения (в GNOME нужно расширение AppIndicator); окно можно вернуть, запустив Tolki ещё раз.
- **macOS:** окно скрывается, Tolki остаётся в Dock — щелчок по значку возвращает окно. Выйти — «Tolki → Выйти» или Cmd+Q.

## Если что-то не работает

Меню **«Помощь → Сохранить логи…»** — в «Загрузках» появится файл `tolki-logs-<дата>.txt`, и откроется папка с ним. На Windows и Linux меню скрыто: нажмите **Alt**, чтобы оно появилось.

Файл можно приложить к сообщению о проблеме. В нём — что происходило в приложении (вход в комнату, связь, ошибки) и сведения о системе. Имён участников, названия комнаты, пароля, ссылки-приглашения и полных IP-адресов там нет: вместо имён — «участник 3f2a», вместо адресов — только их тип, например «публичный 93.x.x.34». Файл обычный текстовый — его можно открыть и посмотреть перед отправкой. Сам Tolki логи никуда не отправляет.

## Новые версии

У организатора и участников должна быть одна версия Tolki. Если версии разные, приложение скажет «Нужна новая версия» — последнюю можно скачать по ссылке выше и установить поверх: недавние комнаты и настройки сохранятся.

- **Windows и AppImage на Linux** обновляются сами: новая версия загружается в фоне, на главном экране появляется «Версия X загружена и установится при выходе из Tolki». Она установится при следующем выходе из Tolki; «Перезапустить» устанавливает сразу.
- **macOS и .deb** — на главном экране «Доступна версия X», «Скачать» открывает страницу с установщиками. На macOS автообновление появится после подписи приложения.
- Альфа- и бета-версии обновляются до следующей альфы, беты или полной версии. Полная версия до альфы не обновляется.

## Проверить файл

Рядом с установщиками лежит `SHA256SUMS.txt`. Контрольная сумма скачанного файла должна совпасть со строкой для него:

- Windows (PowerShell): `Get-FileHash .\Tolki-…-win-x64.exe`
- macOS: `shasum -a 256 Tolki-….dmg`
- Linux: `sha256sum Tolki-…`

## Удалить

- **Windows:** «Параметры» → «Приложения» → Tolki → «Удалить».
- **macOS:** перетащить Tolki из «Программ» в корзину.
- **Linux:** AppImage — удалить файл; `.deb` — `sudo apt remove tolki`.
