# Бюджеты производительности (#34)

Сгенерировано `pnpm perf:budgets`, 2026-10-18.
Машина: Apple M1 Pro, 10 ядер, 16 ГБ, darwin 25.6.0.
Сборка: установочная (`E2E_EXECUTABLE`).

CPU — процессорное время всех процессов приложения из ОС за 30 с после 10 с разгона; «% ядра» — от одного ядра, основная цифра — от всех ядер, как у бюджета хоста в PLAN §6. Память — физический объём всех процессов приложения, как в «Мониторинге системы» на macOS (physical footprint; на Linux — PSS). Сумма working set (RSS) по процессам больше: общие страницы фреймворка Electron, отображённые в каждый процесс, в ней считаются в каждом; она дана для справки.

| Без звонка, окно открыто | ≈ 0 | 0 % (0,4 % ядра) | ✅ |

«≈ 0» засчитывается, если меньше 1 % одного ядра.
